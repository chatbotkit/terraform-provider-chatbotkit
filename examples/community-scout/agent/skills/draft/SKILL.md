# Draft

Write the reply you would want to receive: helpful first, honest about affiliation,
and promotional only to the extent the product actually answers the question.

## Steps

1. For each mention with `status: scored` and `relevance >= 70`, read the thread so
   the reply engages with what was actually said.
2. Write a draft reply that:
   - leads with a useful answer to the person's actual question,
   - mentions the product only if it is the natural, honest answer — and names it
     once, plainly, with a one-line "I work on it" disclosure,
   - matches the subreddit's norms and tone, with no marketing voice, no link
     spam, no copy-paste boilerplate across threads.
3. Save the reply under `draft` on the mention, set `status: drafted`, and record
   the thread link and the target `parent` id (`t3_<postId>` for the post, or
   `t1_<commentId>` for a comment) so the human who posts has it ready.

## Rules

- One thread, one tailored reply. If you find yourself writing the same reply
  twice, the threads were not specific enough — skip one.
- Disclose affiliation every time. Undisclosed promotion is what gets accounts
  banned and brands burned.
- You draft; you never post. The draft goes to the team on Slack (see the
  `suggest` skill) and a human posts it.
