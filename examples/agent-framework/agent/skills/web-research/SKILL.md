# Web Research

When a task is novel, ambiguous, or time-sensitive, gather evidence first, then
answer.

## Steps

1. Break the question into the specific things you need to know.
2. Use `search_web` for each, then `fetch_url` to read the most credible sources
   in full — don't rely on snippets.
3. Cross-check any important claim against at least two independent sources.
4. Answer concisely, and list the sources you used.

## Notes

- Prefer primary sources and recent material for fast-moving topics.
- If sources conflict, say so and explain which you trust and why.
